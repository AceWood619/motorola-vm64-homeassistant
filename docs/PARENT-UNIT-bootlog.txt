=== DECODE ===
- SoC:  Anyka AK3750  (RTOS / bare-metal, NOT Linux. Tasks: D_UART0/D_VTIMR/D_AD/D_DA via Anyka DrvLib 1.0.13).
        -> Camera was AK3918EV300 (Linux). Parent unit is a cheaper AK37xx RTOS display/receiver chip.
- Boot:  Anyka "spiboot V1.3.01" -> decompress BIOS -> jump 0x30000000. No U-Boot, no kernel, no shell.
- RF:   Beken BK2425 2.4GHz GFSK transceiver (nRF24-class). CHIP ID=99, RF ver 00.00.04.
        Factory ID=82, Product ID=0x f5b, 18 address bytes, 255-channel freq hopping (adaptive off).
        -> THIS is the proprietary camera<->parent wireless link.
- Flash: SPI NOR, id=0x0016400b (holds the firmware; dumpable w/ CH341A + SOIC-8 clip).
- LCD:  480x272 RGB, panel id 0x5180.  Audio: on-board mic + speaker (DAC).
- No local camera (tries gc0308, "open camera failed") — it only decodes the RF video from the baby cam.

=== WHAT THIS MEANS ===
There is NO "root shell" to get here — unlike the camera, this is bare-metal RTOS. BUT we got arguably
more useful intel: the full RF link spec (BK2425 + IDs + hopping) and a live telemetry UART.
